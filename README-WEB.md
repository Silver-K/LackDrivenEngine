# 雨停之前

依据 [draft.md](draft.md) v0.7 实现的中文酒馆叙事游戏。三个有各自缺口的人，在一间酒馆里继续生活。没有任务清单、好感度通关或治愈结局。玩家可以靠近、倾听、沉默、离开，也可以只是旁观。

## 开始游玩

需要 **Node.js 20 或以上**，不需要安装依赖、不需要模型密钥。

- Windows：双击 **`开始游戏.cmd`**，保留启动窗口。
- 或在项目目录运行 `npm start`，打开 **http://127.0.0.1:4173**。
- 如果端口被占用，可设置 `PORT` 后运行 `node server.mjs`，打开对应端口。
- 关闭启动窗口或按 `Ctrl+C` 结束服务。

选择沈砚、林遥或周叔，点选相处方式，或输入一句中文。每 10 秒流过 1 分钟；「静坐五分钟」会推进世界。暂停只停止自动流逝，主动交谈和快进仍可使用。去檐下后不能隔空交谈，但能观察 NPC 彼此相处；推门回来即可继续。

「人物手记」展示心绪、记忆和行为因果。没有需要刷满或清零的数值。雨声默认关闭，点击右上角开启。

进度自动存入浏览器 localStorage。设置中可导出/导入 JSON 存档、导出因果记录、重新开始。刷新会延续当前进度。非暂停状态下，重新打开或返回标签页时会补算离线生活，单次最多补算 180 游戏分钟。浏览器关闭期间并无后台进程在持续计算。不同浏览器/端口的存档相互独立。

## 当前版本范围

这是一个完整可玩的 **Web 酒馆沙盒原型**，覆盖文档最小原型，并扩展为三位 NPC 的有向关系网络。采用原生 HTML/CSS/SVG + JavaScript，零运行时依赖，手绘风格酒馆图、合成雨声均在本地生成；未引入外部图片、字体或 CDN。

已实现：

- **持续匮乏**：每人三个锚点、六个内部维度、不可消除的 floor、自然回归和缓慢的经历漂移。没有目标队列、规划器、行动效用评分或 argmax。
- **四档激活**：潜伏 / 浮现 / 牵动 / 淹没；情境显著性、焦点惯性、习惯次序和抑制共同决定注意力。
- **结构合成**：焦点、背景、抑制、部分序防御、同时激活的冲突算子、身体和规范共同形成双向拉扯。顶层防御可能压过其他层，同层矛盾保留。
- **情绪惯性**：平静、敏感、淹没、麻木的状态转换；疲劳和饥饿随时间演化；有休息、吃饭、创作和无事发生的时刻。
- **防刷**：陪伴、宽慰、热茶共享依恋安抚通道；安抚效果衰减，副作用封顶。新模式要求间隔开的安全经历；高压力下旧模式回归。
- **记忆**：保存事件主体、`role`、情感痕迹与可观察行为。类似情境提取时，根据当前心理状态重新解释，保留扭曲历史。潜台词不写入记忆。
- **非玩家中心**：NPC 会相互留茶或疏远，有独立的有向关系与应对模式。玩家离开后仍演化，可独处创作。
- **数据化事件**：事件和词语匹配定义在数据层。可能、假设、否认、多义和无法识别的话进入歧义池，12 分钟后失效，不擅自变为世界事实。
- **观察与追踪**：最近 240 条生活记录、180 条心理轨迹、每人 48 条情感记忆；每个行为能追到事件、锚点、注意力、防御、冲突和安抚变化。
- **持久化与可选表达层**：可恢复存档、导入校验、离线补算、服务端密钥隔离、模型失败回退本地叙事。

自由输入目前采用中文关键词和保守的歧义规则，不是通用语义理解。默认台词来自角色化表达库，因此长时间游玩仍可能重复。手绘场景呈现同一间酒馆，不包含地图移动、背包或任务系统。酒精是预留的身体状态字段，当前游玩不提供劝酒动作。存储采用浏览器本地存档，未引入 SQLite 或跨设备同步。

## 可选模型表达

模型仅润色**已确定的台词**；不能挑选行为、管理关系或修改心理状态。动作和表情必须逐字保留。服务端检查未知字段、越权状态、显式和解语句和动作变更，失败重试一次，再退回本地台词。检查是保守的结构与文本规则，不能保证识别所有自然语言中的隐性和解；因此模型输出完全不回灌心理引擎，因果记录始终保留引擎的原始输出。

服务支持常见的 Chat Completions 兼容 HTTP 接口。在启动前设置：

```powershell
$env:EXPRESSION_API_URL = "http://127.0.0.1:1234/v1/chat/completions"
$env:EXPRESSION_MODEL = "你的模型名称"
# 只有服务要求认证时才设置；密钥留在服务端，不写入代码或浏览器。
$env:EXPRESSION_API_KEY = "你的密钥"
node server.mjs
```

不配置时完全不请求模型。配置远端地址意味着将虚构角色的定性矛盾结构与预置表达发送到该地址；原始玩家输入、存档、数值状态和密钥不会进入前端请求体。整个游戏仍由确定性引擎驱动。外部模型未在本次交付中连接实测。

## 文件结构

| 文件 | 用途 |
|---|---|
| `index.html` | 酒馆场景、人物手记与交互界面 |
| `src/style.css` | 桌面与窄屏布局、视觉风格与动画 |
| `src/data.js` | 人物、锚点、事件 schema、算子、表达库 |
| `src/engine.js` | 纯确定性心理状态转移、世界 tick、存档 |
| `src/expression.js` | 表达输入和输出边界校验 |
| `src/app.js` | 界面、自动时间、存档、声音 |
| `server.mjs` | 仅监听本机的静态服务、可选模型代理 |
| `tests/engine.test.mjs` | 核心理念与系统行为回归测试 |

## 实现宪法

1. 锚点有下限，成长改变应对，不消除缺口。
2. 数值服务于阈值与惯性，不用于挑选最优行动。
3. 焦点不必是最痛处；同层防御可以彼此矛盾。
4. 玩家只是世界中的一个张力来源，其他关系也会留下历史。
5. 规范改变表达通道，不能删掉需要。
6. 暂时安抚真实有效；同一通道不能无限刷取。
7. 允许无聊、创作、休息、沉默和安全时刻。
8. 表达层不能决定事实，潜台词不能写记忆。
9. 自我叙事仅供观察，不作为行为输入。
10. 每一个反应都保留可查的心理因果。
