# 不可隐式变更的架构共识

状态：已与用户达成共识，2026-09-17。适用于后续实现与重构；修改这些边界必须明确说明，不能以调参或兼容为名悄悄改变。

1. 通用引擎负责执行主体规则与推进状态，不内置物种、心理名称、张力公式、固定维数、感受映射或学习方式。
2. 主体结构定义维度、张力函数、参考值（如有；仅作结构比较量，不代表目标）、耦合许可、输出通道、感受函数、可塑性函数与身体响应。结构参数和运行中形成的关联强度分开保存。
3. 通用引擎输出作用贡献集合。每项含来源、通道、方向/量；相反贡献不可提前求和后丢弃。原语的最终合成属于身体层。
4. 身体必须有条件地区分净作用和对抗负荷；如何体现、是否消耗以及如何反馈由具体身体规定，不由引擎普遍规定。
5. 物理环境提供信号、几何、接触、交换。主体感受通道负责映射；引擎不知道“尖锐物导致疼痛”。
6. 标签仅为外部呈现。编号不能掩盖固定心理语义；改变显示名称、移除表现层不应改变因果结果。
7. 可塑性规则属于主体。接口约束读写权限、输入输出和执行顺序，不评选最佳规则；经历决定实际更新。母体有初始化先验，幼体没有强环境释放关联，成长不能按年龄注入知识。
8. 数值方法有稳定性和准确性要求，但不自动成为主体的目标。允许参数不等于任务驱动，禁止隐式奖励、完成任务和动作候选排序。
9. 不能用“所有行为出现”代替边界验证。必须验证独立状态、语义隔离、贡献保留、矛盾负荷、可替换规则、不同维数、关联对照和历史延续。
10. 当前实现只是一个主体家族的实验模型；不声称意识或真实生物心理已实现。
11. 低活动与停留必须来自主体结构、身体反馈和环境作用，不设置“休息”目标、休息动作队列、定时停留或为完成观察而强制访问物品。静止可能来自低驱动，也可能来自相反作用，观察时必须区分。
12. 自身感知不是引擎默认能力，也不是所有主体必有属性。身体可先有真实状态；只有主体结构明确声明的身体量，才能经其自身感受映射进入张力和可塑性。自身感受不授予绝对世界坐标或无损的全知身体读数。
13. 感受来源不决定是否学习。连续外部和连续自身样本默认只影响张力推进；主体结构须明确以变化、跨阈值或许可的稳定模式生成可塑事件。事件的阈值、迟滞、冷却、输入映射和可塑权限均属于主体结构与状态，不能由引擎默认决定。

14. 事件身份由主体许可的数值特征组合决定，不能用样本列表下标、物体身份或显示标签充当记忆身份。多个简单/复合模式可同时激活，各自保存关联向量和迟滞；只释放不再受支持的模式。不同来源不能被任意拼成一个组合。
15. 感受读取无副作用；事件状态只在模拟推进时更新。观察界面读取已提交状态的副本，不重新执行事件检测。保存完整迟滞和感受快照。
16. 训练与探测分离。探测关闭长期可塑性（新建关联、权重、长期统计），允许短期激活与身体变化；等态探测从独立训练快照开始。消退需在已有学习之后开启可塑性重复仅线索。
17. 学习证据依次检查记忆、来源独立的贡献及身体投影；行为相同不等于没有学习。错时对照应按该主体的痕迹衰减尺度构造，不预设错时必然无关联。
18. 当前主体的感受差先通过主体映射影响张力，不把“新异”直接转换为接近力，也不叠加独立的随机转向来制造探索。自主贡献来自逐维张力、张力变化及已学关联；物理外力与碰撞另行保留。删除旁路后不以提高其他推进参数补偿活动量。
19. 当前感受痕迹是总输入的时间平滑历史，不是目标值。总输入与总痕迹相减，保留符号；恒定输入时该差趋近零，不代表全部张力或运动必须归零。零张力但非零变化、运动惯性、外力均需分别判断。

## 运行协议

输入：主体结构、独立状态、经主体感受映射的输入、时间步长。
推进：状态规则 -> 带来源贡献 -> 身体合成与环境接触 -> 主体反馈映射 -> 主体可塑更新。
输出：新状态及未合并贡献。所有主体从同一物理快照感受，随后推进身体，避免按遍历顺序偷读刚发生的运动。
结构定义传给规则的是副本；引擎没有可变主体状态。输出及存档中的关联归主体状态所有。
