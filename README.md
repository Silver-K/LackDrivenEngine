# LackDrivenEngine

**不是更聪明、更有用的人工智能。只是用代码定义规则，让存在自发涌现。**

LackDrivenEngine 是一个匮乏驱动引擎实验。  
它不设目标、不给奖励、不做优化。  
它只做一件事：让主体在内部张力与外部作用的共同推动下持续演化。

> 当前是手工结构参数的实验模型。  
> 不保证形成特定行为，也不证明真实生物心理。

---

## 这是什么

这是一个 **匮乏驱动** 的实验平台。

- 引擎只产生力，不做决策。
- 主体结构定义维度、耦合、感知、表达和身体响应。
- 行为从力叠加与身体承受中涌现，而不是被选择或规划。
- LLM 只在感知层和表达层出现，不参与决策。
- 没有目标函数，没有奖励机制，没有最优解。

它想验证的问题不是“AI 能不能更聪明”，而是：

> 用代码定义规则，存在能不能自己长出来？

---

## 不是什么

- 不是游戏。
- 不是 AI 工具。
- 不是 AGI 项目。
- 不是行为树、效用 AI 或强化学习框架。
- 不追求通过图灵测试。
- 不宣称造出了意识或生命。

---

## 当前能跑什么

启动后，你会看到一个二维空间中的主体：

- 会移动、转向、形变。
- 从空白关联开始，在物理作用与接触中改变状态。
- 形成时序关联与经历痕迹。
- 可保存/读取经历，重置身体，切换环境。

当前有四个可逐步启用的房间：

| 房间 | 观察什么 |
|---|---|
| 空房间 | 身体自身动力与边界作用 |
| 交换 A | 可感知信号与接触后的混合交换 |
| 线索 → 扰动 | 先出现信号，再发生机械扰动 |
| B 与遮蔽 | 不同交换关系与阻挡传播的遮蔽物 |

阶段切换会保留经历。  
同一个结构，在不同经历下，会变成不同的存在。
